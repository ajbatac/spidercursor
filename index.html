SpiderCursor - Lightweight Three.js Procedural Spider Cursor Effect

A realistic, framework-agnostic 8-legged procedural spider that stalks your cursor with inverse kinematics leg physics, real drop shadows, and zero external 3D models.

Key Features

  • Realistic Inverse Kinematics: 8 legs dynamically compute joint angles and footstep cadence in real time.
  • Zero External Assets: 100% procedural geometry and Web Audio synthesis. No 3D model downloads or image sprites.
  • Non-Blocking Click-Through UI: Uses pointer-events: none so every button, link, and input on your website remains completely interactive.
  • 4 Behavioral Modes: Hunt, Flee, Wander, and Perch.

Instant 1-Line Setup

<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<script src="https://unpkg.com/spider-cursor@1.0.0/dist/spider-cursor.umd.js"></script>
<body onload="SpiderCursor.init()">
